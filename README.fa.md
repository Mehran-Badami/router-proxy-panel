# Router Proxy Panel — مدیریت پروکسی روتر

پنل فارسی برای مدیریت Xray، گروه‌های اشتراک VLESS، تست اتصال و بازیابی خودکار.
این پروژه مستقل است و محصول رسمی میکروتیک نیست. هیچ اشتراک، کلید آماده یا
اطلاعات مربوط به شبکهٔ شخصی در بسته قرار ندارد.

**نسخهٔ اولیهٔ آزمایشی:** پیش از استفاده روی روتر اصلی، راهنما و تنظیمات را در
محیط آزمایش بررسی کنید. دستورهای شبکه برای همهٔ روترها یکسان نیستند.

## کار روزمره با پنل

صفحهٔ اصلی سه قدم دارد: بررسی آمادگی روتر، افزودن اشتراک و تست اتصال خودکار،
و انتخاب برنامه‌ها. تنظیمات سرورها و تست سرعت در بخش «پیشرفته» قرار دارند.
نصب اولیهٔ کانتینر، تونل و اتصال امن روتر همچنان طبق راهنمای نصب انجام می‌شود.

## مدیریت سایت‌ها داخل پنل

در بخش «سایت‌های عبوری از VPN» سرویس‌های پیش‌فرض را روشن/خاموش یا ویرایش کنید؛
با «افزودن سایت دلخواه» نام و دامنه‌های خودتان را اضافه کنید. سپس «ذخیرهٔ فهرست»
و «اعمال روی روتر» را بزنید. Google Home و Assistant جدا و پیش‌فرض خاموش هستند.
هر گروه قابل حذف است و آخرین اعمال امکان بازگردانی دارد. اگر اعمال ناموفق شود،
پنل تلاش می‌کند قوانین قبلی را خودکار برگرداند و نتیجه را تأیید کند.
دکمهٔ به‌روزرسانی دامنه‌های پیشنهادی، دامنه‌های تازه را با حفظ انتخاب‌های فعلی اضافه می‌کند.
گروه رسانه‌های مشترک گوگل ممکن است روی سرویس‌های دیگر گوگل هم اثر بگذارد.

اتصال امن پنل به روتر و مسیر تونل باید یک‌بار آماده شوند؛
[راهنمای اتصال و رفتار بازگردانی](docs/SITES.md) را ببینید.
فهرست پیشنهادی تضمین پوشش تمام دامنه‌ها و اتصال‌های هر برنامه نیست.

### اجرای کانتینر

تصویر آمادهٔ عمومی برای AMD64 و ARM64 منتشر شده است:
`ghcr.io/mehran-badami/router-proxy-panel:v0.2.2-beta.1`

دستور کامل اجرای تصویر آماده در [راهنمای اصلی](README.md#local-docker-quick-start)
قرار دارد. برای ساخت مستقیم از کد مخزن، دستورهای زیر را اجرا کنید:

```sh
docker compose up -d --build
docker compose exec panel python /app/manager.py --print-token
```

آدرس `http://localhost:8080` را باز کنید و کلید تولیدشده را وارد کنید. این صفحه
را می‌توانید بوکمارک کنید؛ ورود به‌صورت پیش‌فرض ۳۰ روز نگه داشته می‌شود.
کلید و فایل‌های `/data` خصوصی هستند و نباید در GitHub یا گزارش خطا قرار بگیرند.

اشتراک HTTPS یا لینک‌های VLESS دارای TLS/Reality را وارد کنید و یک سرور انتخاب
کنید. نصب اولیه خالی است؛ تا انتخاب موفق سرور، پروکسی فعال نمی‌شود.
پنل گروه‌ها را جدا نگه می‌دارد و حذف گروه قابل بازگردانی است.

## استفاده در شبکهٔ محلی و میکروتیک

فایل Compose به‌صورت پیش‌فرض فقط روی همان کامپیوتر قابل دسترسی است. برای شبکهٔ
محلی باید `PUBLIC_ORIGIN` را برابر آدرس واقعی پنل قرار دهید و دسترسی پورت‌ها را
در فایروال محدود کنید. پنل و پورت SOCKS را روی اینترنت عمومی باز نکنید.

[راهنمای نصب میکروتیک](docs/ROUTEROS.md) شامل نصب کانتینر، نگهداری داده، DNS امن،
مسیر اضطراری اختیاری و توضیح مسیرگذاری انتخابی است. اجرای کانتینر به‌تنهایی
ترافیک دستگاه‌ها را وارد VPN نمی‌کند؛ مسیرگذاری روتر باید یک‌بار تنظیم شود.
در کد این شاخه، حالت اختیاری TUN داخلی اضافه شده است: پنل، Xray و عبور ترافیک
در یک کانتینر اجرا می‌شوند و دیگر کانتینر جداگانهٔ tun2socks لازم نیست.
این قابلیت هنوز در تصویرهای منتشرشدهٔ قدیمی وجود ندارد؛
[راهنمای نصب نسخهٔ تک‌کانتینری](docs/NATIVE_TUN.md) را ببینید.

در حالت سالم می‌توان DNS را از تونل VPN به Google DoH فرستاد. در صورت انتخاب
صریح مدیر، هنگام خرابی VPN، DNS عادی فعال می‌شود و پس از بهبود برمی‌گردد.
این حالت DNS رمزنگاری‌شده نیست و بازشدن سایت‌های فیلترشده را تضمین نمی‌کند.
اگر همهٔ اشتراک‌ها منقضی شوند، تمدید یا اشتراک جدید لازم است.

حالت خودکار روی سرور سالم می‌ماند و بعد از خطاهای پی‌درپی، جایگزین‌ها را تست
می‌کند. کم‌بودن تأخیر به‌تنهایی تضمین پخش ویدیو یا کارکرد همهٔ برنامه‌ها نیست.

جزئیات متغیرها در [راهنمای انگلیسی](README.md) و نکات محرمانگی در
[SECURITY.md](SECURITY.md) آمده‌اند.

تست سلامت HTTPS تا ۲۵ ثانیه فرصت دارد. خطای موقت جداگانه نمایش داده می‌شود؛
تعویض خودکار پس از سه نوبت ناموفق پیاپی انجام می‌شود. این رفتار سرعت سرور را
افزایش نمی‌دهد و مانع تشخیص خرابی پایدار نمی‌شود.
